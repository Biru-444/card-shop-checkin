# Card Shop Check-in

แอป Flet สำหรับให้ลูกค้าลงทะเบียนก่อนเล่นการ์ด และสรุปยอดรายวัน/รายเดือน

## สิ่งที่ระบบเก็บ

- ชื่อเล่น **หรือ** เบอร์โทร (อย่างน้อยหนึ่งรายการ)
- เกมที่ต้องการเล่น เลือกได้มากกว่าหนึ่งเกม
- วันและเวลาที่ลงทะเบียน โดยบันทึกอัตโนมัติ

ข้อมูลเก็บไว้ใน `card_shop.db` ซึ่งเป็นฐานข้อมูล SQLite ในโฟลเดอร์เดียวกับแอป

## เริ่มใช้งาน

1. ติดตั้ง Python 3.10 ขึ้นไปจาก https://www.python.org/downloads/
2. เปิด PowerShell ในโฟลเดอร์นี้ แล้วรัน:

   ```powershell
   py -m pip install -r requirements.txt
   py -m flet run main.py
   ```

สำหรับเปิดเป็นเว็บบนเครื่องร้าน:

```powershell
py -m flet run --web main.py
```

## หน้าจอ

- **ลงทะเบียน**: ลูกค้ากรอกข้อมูลแล้วเลือกเกมก่อนเริ่มเล่น
- **วันนี้**: จำนวนผู้เข้าใช้ร้านแบบไม่ซ้ำ และจำนวนผู้เล่นแยกเกม
- **รายเดือน**: ยอดสะสมรายเกม วันที่คนเยอะที่สุด และแนวโน้มรายวัน

หมายเหตุ: คนที่เลือกหลายเกมจะนับเป็นผู้เข้าใช้ร้านเพียง 1 คน แต่จะถูกนับในทุกเกมที่เลือกอย่างถูกต้อง
